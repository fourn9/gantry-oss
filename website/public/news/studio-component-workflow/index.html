Gantry Studio:
start with a part.

Review work, files and requirements. Keep the conversation beside the change.

GANTRY TEAM · NOV 07, 2026

Start with the part you need.

Gantry Studio brings software and hardware work into one workspace. In the updated public demo, select a component to see its work, saved files and requirements, then open the conversation that belongs to it.

The sample is now a desktop robot arm. Select Sensor bracket in the left tree: its work opens in the centre, and the same part turns green in the model. The tree stays in place, so you can move to another part without going back to a separate Structure screen.

When an agent needs your input, the question and Reply action come first. Open the reason when you need more context.

Follow the change to its evidence.

One menu switches between Work, Files and Requirements for the selected component. In Work, choose CAD, Code or Checks without another row of tabs.

Open Related beside a file to see its recorded links to requirements, check inputs and work. The full arm stays visible around a selected CAD part, so the detail has a clear place in the project.

Discuss the exact thing you are looking at.

Open Discuss beside a file or requirement. The conversation keeps the saved version it refers to. An Inbox link takes you back to that context, even after newer work exists.

Here, the settling-time requirement and Kai’s request sit side by side. You can see both the question and the missing evidence before replying.

Less searching. More context.

Version history, comparison and detailed records are still there when you need them. Requirements keep their status and open checks in view. The starting point is simpler: choose a part and follow its work.
