A world where
robots build robots.

Robots and agents decide what is needed, build it, and keep it working. They learn, repair, and reuse—forming the roles and knowledge each task needs.

Gantry connects hardware and software work in one shared project. People and agents keep changes, results, and decisions together, while building in the tools they already use.

GET STARTED

Start with
your agent.

Copy the prompt into your coding agent. Tell it your project, goal, and tools. It will help you choose Ledger or Crew and prepare a setup plan for you to review.

VIEW FULL PROMPT
Help me choose and set up Gantry for this robotics project. Use the official repository: https://github.com/fourn9/gantry-oss. Read README.md, docs/SERVICE_SPLIT.md, docs/AGENTS.md, docs/BOT_DEVELOPMENT.md, docs/CREW_ORGANIZATION.md, and SECURITY.md. Ask whether I want Gantry Ledger, where I direct development with recorded evidence and review, or Gantry Crew, where a persistent agent team develops within my delegated scope. Do not set up both unless I ask. Check prerequisites and install Gantry as documented. Identify my project, tools, agent client, goal, and completion conditions. For external tools, read docs/EXTERNAL-INTEGRATIONS.md, docs/EXTERNAL-WRITES.md, and docs/NATIVE-DESKTOP.md. Check the current connection route and limits for each tool I use, distinguish experimental support, and prepare the smallest useful first capture. Keep service credentials out of chat and configuration files; guide me to set them locally. Do not change external records without my approval. For Ledger, prepare a scoped local connection with gantry-ledger connect PROJECT_PATH --client CLIENT --prepare, using the actual path and supported client name. For Crew, follow its onboarding docs and show me the proposed roles, permissions, tools, runtime, and inference use before activation. Keep owner credentials private and preserve existing client settings. Leave activation, worker startup, and paid inference to my approval. Show me what will change and how to verify it.
