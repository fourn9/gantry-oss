## Contract and slices

1. Read/change an explicitly selected existing field through vendor APIs. First
   slice: SOLIDWORKS part dimension, CATIA V5 part numeric parameter, Creo
   Parametric existing model parameter, SOLIDWORKS Electrical project user data.
   No arbitrary method execution, macros, new features, routing or assembly merge.
2. Prepare an immutable plan with observed identity/version/value, input files,
   reason and requirement references. Explicit plan digest and single-operator
   acknowledgement required to apply because desktop APIs do not offer CAS.
3. Before mutation recheck native identity and baseline; preserve dispatch receipt
   durably, never automatically retry uncertain writes; read back and capture
   output. Windows-compatible journal, no import of POSIX-only project runner.
4. Altium Designer PCB and Cadence Allegro use their native scripting hosts;
   implement bounded, inspectable scripts and result collection. Distinguish
   generated source from a script actually executed in a licensed application.
5. Zuken E3.series and Capital: implement only public, source-supported APIs.
   Missing module-specific SDK contracts must be explicit blockers, not fake
   native success. No SDK downloads requiring accounts, licensing or purchase.
6. Publish evidence using existing requirement-linked artifact/checkpoint APIs;
   preserves original bytes and coverage, remains unverified and unadopted.

## Acceptance / threat model

- [x] Synthetic contract tests exercise fixed native calls, output/error handling and persistence.
- [x] Changed document, dirty baseline, wrong project/configuration or version,
      invalid/secret payload and paths outside operator root cannot be written.
- [x] Crash/timeout after dispatch cannot trigger an automatic second write through the same local journal.
- [x] Generated scripts reject code injection; source contains selected-value guards (native execution unverified).
- [x] Synthetic native input/output plus decisions can round-trip into existing Core.
- [x] No licensed product used: catalog/docs say unverified; no physical pass claimed.
- [x] Full regression suite and installed package entry points checked.
- [ ] Windows/licensed application acceptance for all direct drivers.
- [ ] Native script execution and verified save/reopen for Altium/Allegro.
- [ ] Zuken/Capital executable adapters after exact SDK contracts are available.

Assets: local native files, vendor database, credentials/license code, plan and
journal integrity. Untrusted: model-produced changes, imported evidence and file
paths. Caller is a local operator, not a new unrestricted agent MCP permission.
The adapter is not an OS sandbox. COM may continue after client interruption;
uncertain outcomes require read-only reconciliation. Same-user tampering and
concurrent edits in the vendor GUI are outside local locking guarantees.

Commands (existing runtime): `python -m unittest discover -s tests -p
'test_native*.py'`; full `python -m unittest discover -s tests`; wheel with
`python -m pip wheel . --no-deps --no-build-isolation --wheel-dir /tmp/gantry-native-dist`.
