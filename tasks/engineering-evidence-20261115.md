## Capability order and contracts

1. evidence-impact: derived join in existing design assessment, no second store.
   Exact source IDs/hashes/locators and units/frame/time; missing != unaffected;
   contradictory views remain conflicting. Actual diff first, intent prediction
   explicitly unsupported unless a separately labeled contract is implemented.
2. verification-plan: Bot action records purpose, selected frozen check/tool,
   known inputs/criteria, assumptions and next branches in existing action ledger.
   No arbitrary commands or weakening fixed criteria. Existing tool/publish routes.
3. native-loop: anonymous carrier CAD and executable control/calibration evaluator.
   CAD generation and read-only verification separate. Real OCP, no commercial
   tool/hardware/strength/dynamic claim. Three Bots choose edits and delegation.
4. studio: compact Checks details with provenance, unchanged discussion paths.
5. validation: tests + live subscription models, then held-out A/B if comparable.
