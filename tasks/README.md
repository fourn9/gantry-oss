# Implementation records

Contributor reference, not a user onboarding guide or an automatically executable work queue.
These files preserve acceptance criteria, decisions, completed slices and unresolved work.
A checked box applies to that task's scope; it does not establish universal tool support or engineering success.

Use [documentation](../docs/README.md) for current operation and [verification records](../docs/VERIFICATION.md) for evidence. Check the relevant source and issue before treating an old plan as current.
